# 聚合图床（账号登录版）

模拟网页版聚合图床上传方式，不需要付费API Key，输入账号密码即可直接使用。

<mark>此插件要求Picora v1.0.4或更高版本，低于要求可能无法安装或正常使用！</mark>

## 配置

1. 在 Picora 中安装此 ZIP 插件。
2. 新建「聚合图床（账号登录）」配置，填写用于登录 `www.superbed.cn` 的账号和密码。账号可以是邮箱或用户名，插件会自动判断。
3. 选择图片上传。

## 说明
- 插件先向 `https://www.superbed.cn/api/v1/auth/login` 登录：账号含 `@` 时只发送 `email` 字段，否则只发送 `username` 字段。Picora 将返回的访问令牌暂存于内存，再向同一主机的 `/api/v1/upload/` 上传图片。密码仅用于登录请求；上传请求只发送访问令牌和图片。令牌过期后会重新登录一次。

- 此适配依据 2026 年 10 月的网页版请求流程编写，属于第三方非公开接口，网站更新后可能失效。

- 网页版对超过 10 MiB 的文件改用分块上传；此插件只实现普通单文件上传，建议使用不超过 10 MiB 的图片。
